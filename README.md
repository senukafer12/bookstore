# 📚 RESTful Bookstore API

A comprehensive e-commerce backend API for a bookstore built with Java and JAX-RS (Jersey). This production-ready API implements full CRUD operations for managing books, authors, customers, shopping carts, and orders with proper authentication and validation.

## 🚀 Key Features

- ✅ Complete RESTful endpoints with proper HTTP status codes  
- ✅ JAX-RS (Jersey) implementation with JSON support  
- ✅ In-memory data storage with thread-safe operations  
- ✅ Comprehensive error handling with custom exceptions  
- ✅ Shopping cart and order management system  
- ✅ Unit and integration testing with Postman  
- ✅ Proper documentation with Swagger/OpenAPI
